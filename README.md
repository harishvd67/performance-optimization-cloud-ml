Performance Optimization in Cloud Computing Using Machine Learning

# 📌 Project Overview

This project focuses on optimizing cloud resource utilization using
machine learning techniques. The system analyzes cloud resource
metrics and predicts system latency to support efficient resource
management.

The application is developed using Python and Django, with MySQL
for database management and machine learning techniques for
performance prediction.

🎯 **Objectives**

- Predict cloud system latency
- Improve cloud resource utilization
- Reduce response time
- Support efficient resource allocation
- Provide a web-based platform for performance prediction

## 🛠️ Technologies Used

- Python
- Django
- MySQL
- Scikit-learn
- SVM
- Decision Tree
- HTML
- CSS
- JavaScript

## 🤖 Machine Learning Approach

The project uses machine learning algorithms to analyze cloud
resource metrics and predict system performance.

### Algorithms Used

- Support Vector Machine (SVM)
- Decision Tree

## 📊 Input Parameters

- CPU Usage
- Memory Usage
- Network Usage
- Disk I/O
